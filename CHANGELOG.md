# Change Log

All notable changes to the "refreshr" extension will be documented in this file.

## [0.0.1] - 2026-08-03

- Initial release of **Refreshr**.
- Added health reminders for:
  - Drinking water (💧)
  - Resting eyes with the 20-20-20 rule (👀)
  - Standing up and stretching (🚶)
- Added visual status bar showing active countdowns.
- Created convenient quick-pick menu options.
- Implemented daily and lifetime completion stats.
